#  Wasselni — Home Services & Delivery App

**Wasselni** is a Flutter-based application designed to simplify requesting and tracking home services and delivery orders through a user-friendly mobile experience.

The project is being developed in three main phases: the **Customer App**, the **Delivery Driver App**, and the **Admin Dashboard**.

The first phase, the Customer App, has been completed, and development will continue with the remaining components.

---

##  Project Overview

Wasselni aims to provide a convenient way for customers to create service and delivery requests, manage their personal information, save addresses, and track their orders.

The application is built with Flutter and Firebase, with a focus on reusable widgets, state management, localization, and a structured codebase.

##  Customer App Features

###  Authentication & Profile Management
- User registration and login.
- Firebase Authentication integration.
- Profile information management.
- Edit personal information.
- Profile image handling.

###  Order Management
- Create new orders.
- Choose between **Pickup & Delivery** and **Delivery Only**.
- Enter pickup and delivery locations.
- Add order details and additional information.
- Calculate order pricing using configurable pricing logic.
- View orders and their current statuses.

###  Order Tracking
- Track orders through different statuses.
- View order details and delivery information.
- Display an order timeline.
- View delivery driver information.

###  Notifications
- Dedicated notifications screen.
- Display order-related notifications and updates.

###  Address Management
- Add new addresses.
- Edit saved addresses.
- Delete addresses.
- Organize addresses by type, such as Home and Work.

###  Settings & User Experience
- Arabic and English localization.
- Profile settings.
- Reusable logout confirmation dialog.
- Consistent UI components and navigation.
- Responsive layouts for a smooth mobile experience.
